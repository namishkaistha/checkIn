# Pantry Check-In Frontend

React 19 + Vite 6 + TypeScript (strict) + React Router 7 + react-i18next + Storybook 8.

## Development

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # vitest (atom + hook tests)
npm run storybook    # http://localhost:6006
npm run build        # type-check + production build
```

This package only contains M3 deliverables: design tokens, the i18n setup, the
router shell with placeholder routes, and atom-level components. Molecules,
organisms, templates, and real pages land in M4.
